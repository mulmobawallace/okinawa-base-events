# 沖縄 米軍基地イベント情報サイト

## ファイルの役割

| ファイル | 役割 | 編集する？ |
|---|---|---|
| `events.js` | イベントのデータ | **ふだんはここだけ編集** |
| `bases.js` | 基地のデータ（地図の位置・日本語の呼び名・アクセス） | 基地を増やすとき |
| `map.html` / `map.js` | 基地マップのページ | ほぼ触らない |
| `index.html` | ページの骨組み・はじめての方へガイド | ときどき |
| `style.css` | 見た目（色・文字サイズ） | たまに |
| `app.js` | 一覧表示・絞り込みのプログラム | ほぼ触らない |

## イベントの追加方法

1. `events.js` を開く
2. `{` から `},` までのかたまりを1つコピーし、すぐ下に貼りつける
3. 中身を書きかえる（日付は `2026-11-14` のように **年-月-日** の形で書く）
4. 保存して、`index.html` をブラウザで開き直す

- 中止になったら `status: "中止"` に変える（カードに赤い「中止」のタグが付く）
- 終了したイベントは自動で一覧から消える（「終了したイベントも表示」にチェックすると見られる）
- `sourceUrl` には公式ページのURL、`checkedAt` には公式情報を確認した日付を必ず入れる

- `base` は `bases.js` の `name` と**まったく同じ書き方**にする（そうすると基地名から地図へリンクされる）

## 日程未発表のイベント

正式な日付がまだ出ていないイベントは、次のように書くと「2027年4月ごろ（日程未発表）」と表示されます。

```js
status: "日程未発表",
expected: "2027年4月ごろ",   // 画面に出る目安
startDate: "2027-04-01",     // 目安の月の初日（並び順に使う）
endDate: "2027-04-30",       // 目安の月の末日（この日を過ぎると「終了」扱い）
```

**正式発表されたら**：`startDate` / `endDate` を本当の日付に、`status` を `"予定"` に変え、`time`・`gate` などを埋める（`expected` は消しても残してもOK）。
